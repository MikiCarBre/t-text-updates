# T-Text

Ovde se objavljuju gotove verzije aplikacije **T-Text** (beleške, table, alarmi) za Windows.

**Preuzimanje:** [najnovija verzija](https://github.com/MikiCarBre/t-text-updates/releases/latest) → `T-Text.zip` → raspakuj → pokreni `T-Text.exe`.

Instalirani T-Text se sam ažurira odavde. Beleške se čuvaju odvojeno od aplikacije i ažuriranje ih nikad ne dira.
